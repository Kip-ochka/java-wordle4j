# java-wordle4j

Консольная игра «Wordle» на русских словах: компьютер загадывает существительное
из пяти букв, у игрока шесть попыток. Компьютер умеет играть и сам — достаточно
нажимать Enter.

## Правила

После каждого хода программа печатает под введённым словом строку-подсказку:

| Символ | Значение                                        |
|--------|-------------------------------------------------|
| `+`    | буква есть в слове и стоит на своём месте       |
| `^`    | буква есть в слове, но стоит в другом месте     |
| `-`    | такой буквы в слове нет                         |

```
гонец
+^-^-
```

Слово засчитывается за ход, только если оно состоит из пяти русских букв и есть
в словаре. Пустая строка (просто Enter) — просьба о подсказке: компьютер
подбирает слово, не противоречащее всем прошлым ходам, и делает им ход.

## Запуск

```bash
javac -encoding UTF-8 -d out $(find src -name '*.java') && java -cp out ru.yandex.practicum.Wordle
```

Программу нужно запускать из корня проекта — рядом лежит файл словаря
`words_ru.txt`. Другой словарь можно передать первым аргументом командной строки.
Служебные сообщения и стектрейсы не попадают в консоль, а дописываются
в файл `wordle.log`.

## Структура проекта

| Класс                    | Ответственность                                                              |
|--------------------------|------------------------------------------------------------------------------|
| `Wordle`                 | главный класс: лог, загрузка словаря, игровой цикл, весь ввод и вывод         |
| `WordleGame`             | состояние партии, ходы, проверка ответа, поиск слова-подсказки                |
| `WordleDictionary`       | список игровых слов, нормализация, фильтрация, побуквенное сравнение          |
| `WordleDictionaryLoader` | чтение файла словаря в кодировке UTF-8                                        |
| `GameState`, `MoveResult`| состояние игры и результат одного хода                                        |
| `exception.*`            | отдельные иерархии исключений для ошибок программы и для игровых ситуаций     |

Кроме `Wordle`, ни один класс не обращается к консоли: лог передаётся во все
классы как `PrintWriter`.

## Тесты

Юнит-тесты (JUnit 5) лежат в папке `test`, библиотеки — в `lib`. Запускать удобнее
всего из IntelliJ IDEA; рабочей папкой должен быть корень проекта, иначе тесты
на настоящем словаре будут пропущены.
